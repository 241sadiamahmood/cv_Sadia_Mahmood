2. Open `index.html` in a modern browser.
3. For best results, stay connected to the internet so externally hosted fonts and icons can load.

## Research project note
Project 01 is a proposed student laboratory study: investigating how sugarcane molasses concentration affects baker’s yeast fermentation activity. It is clearly labelled as a proposal, not completed research. pH, soluble-solids (°Brix), and CO₂ observations are process indicators; they do not directly quantify ethanol. Actual ethanol concentration requires a validated assay or suitable analytical instrument. Carry out the work only with supervisor approval and the institution’s laboratory safety procedures.

Project 02 is a proposed amylase-on-starch laboratory study using an iodine-starch observation assay. Project 03 is a proposed starch-based film formulation study examining glycerol-related physical properties. Both are clearly labelled as proposals, not completed experiments. Confirm protocols, reagents, controls, and safety with a laboratory supervisor. Visual iodine colour scoring is semi-quantitative; do not claim exact enzyme activity without a validated quantitative assay. Do not claim biodegradability without a defined degradation test.
